# Security Policy

## Reporting a vulnerability

Please do not publish credentials, private learning files, or exploitable details in a public issue.

Use GitHub's private vulnerability reporting feature when it is available for this repository. Include the affected component, reproduction steps, impact, and a suggested mitigation if known.

## Data boundaries

- The local workspace stores learning state in the current browser by default.
- Learning-state files should not contain credentials or protected personal data.
- Imported source material should remain within the user's authorized environment.
- The project records concise evidence summaries rather than hidden chain-of-thought.
