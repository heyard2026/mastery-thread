# Mastery rubric

## Purpose

Use this rubric to award the highest mastery level supported by observable performance. A level describes evidence for one capability, not a global judgment about the learner.

## Levels

| Level | Meaning | Minimum acceptable evidence | Insufficient evidence |
|---|---|---|---|
| L0 | Not yet evidenced | No valid attempt, or an attempt showing no usable foundation | Exposure, attendance, confidence |
| L1 | Recall | Retrieve key facts, labels, steps, or syntax with little or no prompting | Recognition from options alone; copying notes |
| L2 | Explanation | Explain relationships and boundaries in the learner's own words; distinguish a relevant counterexample | Repeating a memorized definition; explanation built through leading hints |
| L3 | Application | Complete a representative task independently and check the result | Following a nearly identical worked example; success without verification |
| L4 | Transfer | Adapt the capability to a materially different context, justify choices, and handle an exception | Cosmetic variation of the L3 task |

## Promotion gates

Promote only when all conditions for the proposed level are met:

1. **Correctness**: the central result is correct.
2. **Independence**: support did not determine the decisive step.
3. **Reasoning**: the learner can expose enough reasoning to diagnose errors without requiring hidden chain-of-thought.
4. **Verification**: the learner checks or defends the result using an appropriate method.
5. **Freshness**: evidence is recent enough for the project's risk and deadline.

For L3 and L4, require at least one clean attempt after any corrective explanation.

## Evidence strength

Rank evidence from strongest to weakest:

1. authentic work product with an external check;
2. novel transfer task with defensible reasoning;
3. representative application task;
4. explanation plus counterexample;
5. free recall;
6. recognition, rereading, or self-reported confidence.

Use weak evidence for diagnosis, not for high-level promotion.

## Hint accounting

Record the strongest help used:

- `none`: no substantive help;
- `clarification`: wording clarified without revealing a step;
- `cue`: points toward a relevant concept;
- `scaffold`: supplies part of the method;
- `worked-step`: supplies a decisive step;
- `solution`: supplies the answer.

Evidence using `worked-step` or `solution` cannot independently support L3 or L4.

## Confidence in a level

Store a confidence value between 0 and 1 based on evidence consistency, not model certainty theater:

- `0.90–1.00`: multiple consistent, recent attempts including application or transfer;
- `0.70–0.89`: one clean direct attempt plus supporting evidence;
- `0.50–0.69`: partial or highly scaffolded evidence;
- below `0.50`: diagnostic signal only.

## Regression

Do not automatically erase historical mastery after one failed review. Lower current confidence, reopen a weakness, and collect another attempt. Lower the level only when repeated evidence shows the capability is no longer reliable.

## Route defaults

- Knowledge understanding: target L2 unless the use case demands application.
- Practical skill: target L3.
- Professional research: target L3 with source-quality evidence.
- Exam or certification: map the target to tested behavior; usually L2 for conceptual items and L3 for problem solving.
