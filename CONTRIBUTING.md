# Contributing to MasteryThread

Thank you for helping improve evidence-based learning workflows.

## Useful contributions

- Real learning cases that expose a weak mastery decision
- Reproducible state migration or resume problems
- Improvements to accessibility, mobile behavior, or state portability
- New deterministic tests for the bundled scripts
- Clear documentation fixes that reduce installation friction

## Before opening an issue

Please include:

1. The learning goal or workflow
2. What you did
3. What happened
4. What you expected
5. A minimal redacted `learning-state.json` when state behavior is involved

Do not include credentials, private source material, protected personal data, or hidden chain-of-thought.

## Pull requests

- Keep each pull request focused on one problem.
- Add or update tests for deterministic behavior.
- Run the Skill and frontend checks documented in the root README.
- Preserve unknown fields when changing the learning-state schema.
- Explain user impact and any state migration implications.
